1.🔄 Function Overloading

Description:
Demonstrates compile-time polymorphism by using multiple functions with the same name but different parameters. It shows how C++ selects the appropriate function based on the arguments passed.

2. 📐 Area Calculator using function overloading

Description:
Creates an area calculator using function overloading to calculate the area of different shapes such as a circle, rectangle, and square. It demonstrates how the same function name can perform different calculations.

3. ➖ Unary Minus Operator

Description:
Demonstrates operator overloading by redefining the unary minus (-) operator for a user-defined object. It changes the sign of the object's data members.

4.🔢 Prefix & Postfix Increment

Description:
Demonstrates overloading of both prefix (++obj) and postfix (obj++) increment operators. It shows the difference between increasing an object's value before and after its current value is used.

5. ➕ Complex Number Addition

Description:
Demonstrates binary operator overloading by using the + operator to add two complex number objects. It makes user-defined objects behave like normal mathematical values.

6. ⚖️ Relational Operator Overloading

Description:
Demonstrates overloading of relational operators such as >, <, and ==. It allows objects to be compared based on their data members.

7. 🤝 Friend / Non-Member Operator

Description:
Demonstrates how an operator can be overloaded using a friend or non-member function. It shows how operators can access private class data with the help of a friend function.

8. 🧩 Base Pointer Without Virtual

Description:
Demonstrates the behavior of a base class pointer pointing to a derived class object without using virtual. It shows that the base class function is selected at compile time.

9. ⚡ Base Pointer With Virtual

Description:
Demonstrates runtime polymorphism using a virtual function and a base class pointer. The appropriate derived class function is selected according to the actual object at runtime.

10. 🔗 Base Reference With Virtual

Description:
Demonstrates runtime polymorphism through a base class reference. A base reference refers to a derived object and calls the derived implementation of the virtual function.

11. 🏛️ Abstract Class & Pure Virtual Function

Description:
Demonstrates the use of an abstract class and pure virtual function to define a common interface for derived classes. It ensures that derived classes provide their own implementation of the required function.

12. 🎨 Polymorphic Shape Pointers

Description:
Creates a collection of base-class pointers to different shape objects and uses virtual functions to calculate their areas. It demonstrates practical use of runtime polymorphism.

13. 🗑️ Virtual Destructor

Description:
Demonstrates the importance of a virtual destructor when deleting a derived object through a base class pointer. It ensures proper destruction of both derived and base class objects.

14.✂️ Object Slicing

Description:
Demonstrates object slicing, which occurs when a derived class object is copied into a base class object. The derived-class-specific data and behavior are not retained in the copied base object.

15. 💳 Payment Processing System

Description:
Creates a simple payment processing system using polymorphism. Different payment methods can implement their own payment process while sharing a common base interface.

16. 👨‍💼 Employee Payroll Mini-Project

Description:
Develops a small employee payroll system using OOP concepts. It manages employee information and calculates salary according to different employee types, demonstrating inheritance, polymorphism, and encapsulation.
